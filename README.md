# More Tools

A Forge mod for **Minecraft Java 26.3** that adds 26 new tools.

**[⬇ Download the latest .jar](https://github.com/benmatt140/more-tools-mod/releases/latest)**

## What's in it

| Tool | Tiers | What it does |
|---|---|---|
| **Emerald tools** (sword, pickaxe, axe, shovel, hoe) | — | Diamond-level mining, a bit faster than diamond, 1200 uses, easiest tools in the game to enchant |
| **Obsidian tools** | — | Diamond-level mining, slower, but 2800 uses and hit harder |
| **Amethyst tools** | — | Iron-level mining but the **fastest** tools in the game, only 400 uses |
| **Hammer** | Iron, Diamond, Netherite | Mines a **3×3** area of stone/ores. Skips blocks much harder than the one you hit (so you won't accidentally dig obsidian) |
| **Excavator** | Iron, Diamond, Netherite | Digs a **3×3** area of dirt, sand, gravel, etc. |
| **Lumber Axe** | Iron, Diamond, Netherite | Chops down a **whole tree** at once (up to 256 logs). Only triggers on real trees with natural leaves, so log cabins are safe |
| **Paxel** | Diamond, Netherite | Pickaxe + axe + shovel in one, 2× durability |

**Tips**
- **Sneak (Shift)** while mining to use a hammer, excavator or lumber axe on a single block.
- Big tools (hammer, excavator, lumber axe) last 3× longer than normal tools but dig a bit slower. Each extra block broken uses 1 durability.
- Netherite versions don't burn in lava.
- All tools can be enchanted and repaired like normal tools. Everything is in the **More Tools** creative tab.

## Recipes

`X` = material, `#` = stick

| Tool | Pattern | Materials |
|---|---|---|
| Sword / Pickaxe / Axe / Shovel / Hoe | Same shapes as vanilla tools | Emerald, Obsidian (block) or Amethyst Shard |
| Hammer | `XXX` / `X#X` / ` # ` | Iron Ingot or Diamond |
| Excavator | ` X ` / `X#X` / ` # ` | Iron Ingot or Diamond |
| Lumber Axe | `XXX` / `X# ` / ` # ` | Iron Ingot or Diamond |
| Diamond Paxel | Shapeless: Diamond Pickaxe + Diamond Axe + Diamond Shovel | — |
| Netherite versions | Smithing Table: Netherite Upgrade + diamond tool + Netherite Ingot | — |

## Installing

1. Open the Minecraft Launcher and play **Minecraft 26.3** once (plain, no mods), then quit.
2. Download the **Forge installer for 26.3** from https://files.minecraftforge.net/net/minecraftforge/forge/index_26.3.html (click *Installer*).
3. Run the installer, choose **Install client**, click **OK**.
4. In the Minecraft Launcher, pick the new **forge** profile, play once, then quit.
5. Put `moretools-26.3-1.0.0.jar` into your `mods` folder:
   - Windows: press `Win + R`, type `%appdata%\.minecraft\mods`, press Enter
   - macOS: `~/Library/Application Support/minecraft/mods`
   - Linux: `~/.minecraft/mods`
6. Launch the **forge** profile. Click **Mods** on the title screen to check *More Tools* is listed.

For multiplayer, the server and every player need the mod.

## Building it yourself

Needs Java 25. Run `./gradlew build`; the jar appears in `build/libs/`.
Every push to `main` is built, tested on a real Minecraft server (see `src/gametest`), and published as a release automatically.
Textures and data files are generated by `tools/gen_textures.py` and `tools/gen_data.py`.
